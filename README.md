# Aether-guild-open-realms-chapter-1
Step into Aether Guild: Open Realms, a vertical action RPG built for smooth mobile and web play. Switch between four unique mages (Ignis, Glacius, Aurelia, and Volt), explore interconnected sky realms, hunt wild beasts for extra gold and healing orbs, and face powerful level bosses—including the Malakor Eclipse Emperor. ​
